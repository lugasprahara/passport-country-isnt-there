An open passport spread of the **Republic of Ilvara**, a country that isn't there: a bilingual data page (portrait, ghost image, machine-readable zone with correct ICAO check digits) facing a visas page whose stamps tell one consistent story — Drevania in autumn 2023, Kharat in February 2024, Caldera by sea in May 2025, home to Selmaris a fortnight later. The telling detail is printed, not stamped: the bearer, Ana Soren Velmar, is licensed keeper of the Selmaris Light, exempt from harbour dues — and bound by her condition of travel to return to her light within forty days of any departure.

`render.py` draws the spread with PIL; `main.ts` delivers it deterministically.

## Run it

```sh
node main.ts
```

Writes the spread to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).
